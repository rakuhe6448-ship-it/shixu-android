# 1.4.0：历史管理、自动配色与经典构成

日期：2026-11-06。versionCode 6，Room schema 保持 2，AI 草稿协议及 JSON 格式保持兼容。

## 功能与数据边界

- 聊天页右上角提供清空历史，每条消息提供删除按钮及长按菜单，均需确认。请求 AI、提交卡片、导入图片或备份操作进行时，删除入口禁用。
- 单条删除清空正文、分享文字、图片路径、引用和操作建议，只保留标记 DELETED 的空 ID 行，保证历史与事项草稿关联仍合法。列表与 AI 近期上下文排除空行；其他消息的引用显示为已删除。独立事项草稿可从顶部重新核对。
- 清空历史在一个 Room 事务中清理消息、消息关联和所有事项草稿，将变更记录的消息来源置空。正式事项、提醒、任务版本及变更内容保留；已交给系统时钟的闹钟不受影响。
- 删除返回不再被其他消息使用的图片名，ViewModel 在 IO 线程清理，保留当前编辑框正在使用的图片。文件清理失败会提示，不将失败冒充完整清理。备份兼容空消息标记，拒绝包含残留正文／图片的 DELETED 记录。
- 新建事项使用本地稳定色板，先减少同日期重叠事项的颜色冲突，再考虑全局使用数量；同批 AI 新建也参与分配。八种颜色用完后会复用，不能承诺无限唯一。用户显式颜色与已保存事项颜色保留；手动编辑器可关闭自动配色。旧版无日期且仍为默认绿色的事项首次加入排期时也自动选色。

## 视觉与交互

- 默认改为纸白、朱红、炭黑与赭黄，粗体标题、编号栏、几何标记、细边线、小圆角；统一月历、待办、提醒、聊天、编辑、权限引导、设置及启动图标。
- 深色模式提高强调色亮度；文字按背景亮度选择深／浅前景。旧版默认主题色升级到新默认，其他自定义颜色保留，可在外观设置恢复经典构成配色。
- 页面使用短淡入过渡；月份切换增加横移和淡入淡出；日期选择颜色、周行展开、卡片高度及列表增删有过渡。聊天首次加载直接定位底部，删除不强制跳到底部；正在阅读旧消息时，新回复不打断当前位置。动画使用 Compose 动画机制。

## 小组件

- 三种组件均按宽高和系统字体比例计算标题、正文字号、边距及可显示行数，不再仅改变面板。字号有上下限，窄组件优先换行和截断，避免文字无限放大。
- 月历移除固定周高上限，根据剩余高度分配周行；日期、标题和事项字号跟随尺寸改变。优先保留日历，按实际待办数量预留最多三行摘要，不为空列表预留无用区域。
- 今日与近日组件在高度允许时显示大号日期，条目按空间显示分类和截止时间，底部信息固定在下方。没有待办时显示明确空状态。
- Android 12+ 最多提供四个代表性宽高布局，并按版本数限制月历位图预算；旧系统仍响应当前方向尺寸。日期与事项点击入口、主题及透明度保留。
- 新增的 RemoteViews 行高设置使用系统可远程调用的方法，核对依据为 [AOSP View.setMinimumHeight](https://android.googlesource.com/platform/frameworks/base/+/ed841cb/core/java/android/view/View.java)。具体占位与可拖动范围仍由桌面决定。

## 手机试用与待补验证

1. 覆盖安装 1.4.0，确认已有任务、颜色及提醒保留；默认主题切换，自定义色仍可使用。
2. 手动添加同日期的多个事项，检查自动颜色不同；手选颜色后修改日期，确认仍使用手选颜色。AI 一句话创建多个事项，核对卡片颜色后保存。
3. 删除一条带图片且有关联事项的聊天消息，检查引用占位、已保存事项及顶部草稿；再清空历史，确认正式事项与提醒保留。
4. 在排期左右切月、展开多行事项、切换导航；在聊天查看旧消息时接收回复，确认位置不被打断。
5. 添加三种组件，分别试窄长、宽矮、较大尺寸以及深色／浅色和系统大字体。检查字号、摘要行数、日期点击、事项点击及内容溢出。若桌面缓存旧布局，可移除并重新添加组件。
